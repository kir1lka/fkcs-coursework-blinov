# Курсовая работа по ФКЦС

Репозиторий содержит исходные материалы, примеры Multisim, лабораторные работы и текущую версию курсовой работы Блинова Кирилла Игоревича, группа 12002408.

## Как продолжить работу на другом ПК

1. Скопировать или клонировать весь репозиторий.
2. Открыть корневую папку репозитория в Codex.
3. Написать: `Прочитай AGENTS.md и STATUS.md, затем продолжи с ближайшего незавершенного этапа`.
4. Перед изменениями проверить `git status`, после законченного этапа обновить `STATUS.md` и `CHANGELOG.md`.

Файлы, которые дают полный контекст:

- `AGENTS.md` — обязательные правила для следующего помощника;
- `STATUS.md` — текущая точка остановки;
- `PLAN.md` — этапы курсовой и критерии готовности;
- `docs/variant.md` — точные исходные данные варианта;
- `docs/decisions.md` — уже принятые решения и ограничения;
- `docs/handoff.md` — порядок передачи работы между ПК и сессиями.

## Актуальный результат

Канонический Word-файл: `deliverables/Курсовая_Блинов_текущая.docx`.

Сейчас он содержит 5 страниц: титульный лист, план, содержание, техническое задание, таблицы варианта и начало раздела `2.1.1 Порядок синтеза` с графом состояний.

## Структура репозитория

- `deliverables/` — актуальные результаты, которые можно сдавать или продолжать;
- `моя курсовая данные/` — исходные изображения варианта и рабочие копии;
- `ГОТОВЫЕ КУРСОВЫЕ 2026/` — основной образец оформления;
- `пример курсовой/` — методические примеры и схемы Multisim;
- `лабы/` — лабораторные и справочные материалы;
- `docs/` — контекст, решения и правила продолжения;
- `_docx_work/` — временные рендеры и сборочные файлы, в Git не входят.

## Git

Репозиторий хранит бинарные учебные материалы обычным Git. Самый большой файл меньше 10 МБ, поэтому Git LFS пока не требуется. Удаленный репозиторий не настроен: при необходимости его можно добавить позже командой `git remote add origin <URL>`.
