# Подключение общей схемы Multisim по текущим блокам

Эта памятка относится к снимкам пользователя от 25.09.2026: `HB1 Logic_D`, `HB2 D_Counter`, `HB3 DC`, `HB4 CLK_GEN` и `HB5 P_RES_GEN`. Рисунки в `deliverables/integration_guide/` показывают ручную сборку, а не результат моделирования. Имена выводов взяты с присланных снимков.

## Что уже есть на листе

`Logic_D → D_Counter`, шина обратной связи `Bus2`, HEX-индикатор и четыре канала Q на XLA уже подключены. Сохранять эти связи. Четыре выхода `D3…D0` находятся на `Bus1`. На снимке пробники D есть; их можно оставить.

Перед переходом на новый генератор отсоединить старый `Digital Clock 20 Hz` от `HB2:CLK` и `XLA1:C`. Старый внешний цифровой источник/ключ на `HB2:P_RES` также отсоединить. Два независимых выхода не должны одновременно управлять одной цепью. Глобальные `VCC = +5 В` и `GND` должны существовать на листе; у TTL-корпусов проверить питание и землю внутри блоков.

## Точные связи новых блоков

| Источник | Назначение | Что сделать |
|---|---|---|
| `HB5 P_RES_GEN:P_RES` | `HB2 D_Counter:P_RES` | Общая начальная установка кода `D = 1101`. |
| `HB5 P_RES_GEN:P_RES` | `HB4 CLK_GEN:P_RES` | До снятия сброса держит генератор выключенным. Это та же цепь, что в строке выше. |
| `HB2 D_Counter:Q3` | `HB4 CLK_GEN:Q3` | Первый вход точного детектора кода `10 = 1010`. |
| `HB2 D_Counter:NOT_Q2` | `HB4 CLK_GEN:NOT_Q2` | Второй вход детектора. |
| `HB2 D_Counter:Q1` | `HB4 CLK_GEN:Q1` | Третий вход детектора. |
| `HB2 D_Counter:NOT_Q0` | `HB4 CLK_GEN:NOT_Q0` | Четвёртый вход детектора. |
| Новый `Interactive Digital Constant`, исходно `1` | `HB4 CLK_GEN:START_N` | Для пуска кратко дать `1 → 0 → 1`. Не подключать к `P_RES`. |
| `HB4 CLK_GEN:CLK` | `HB2 D_Counter:CLK` | Единственный источник тактов ПСУ. |
| `HB4 CLK_GEN:CLK` | `XLA1:C` | Только при проверке выходов `Y` в режиме External (C). |

На вашем снимке `CLK_GEN` уже содержит `HB6 STOP_UNIT`, `U44A 74AS74N`, `LM555CN` и `74LS04N`. Внутри него `STOP_SIG` от AND4 подан на `U44A:D`; `P_RES` — на `/PRE`; `START_N` — на `/CLR`; инверсный выход `/Q` разрешает таймер через `RST`; выход инвертора даёт `CLK`. Поэтому ещё один `STOP_UNIT`, триггер RUN или AND2 на главном листе не нужен.

Для U44A не удерживать `P_RES=0` и `START_N=0` одновременно: это одновременное включение асинхронных `/PRE` и `/CLR`. Импульс `START_N` подают только после возвращения `P_RES` к `1`.

Ключ `S1 (Key = Space)` находится **внутри** `P_RES_GEN` и создаёт общий сброс. Показанный на главном листе старый внешний `Key = 1` для `P_RES` больше не нужен. `START_N` — отдельный новый цифровой источник с исходным уровнем `1`.

## Подключение DC

Входы `HB3 DC` на вашем снимке расположены сверху вниз так:

| Вход HB3 | Подать выход HB2 |
|---|---|
| `NOT_Q0` | `NOT_Q0` |
| `Q0` | `Q0` |
| `NOT_Q1` | `NOT_Q1` |
| `Q1` | `Q1` |
| `NOT_Q2` | `NOT_Q2` |
| `Q2` | `Q2` |
| `NOT_Q3` | `NOT_Q3` |
| `Q3` | `Q3` |

Можно вести восемь отдельных проводов либо использовать ответвления существующей `Bus2` с точными именами линий. Шина Multisim является контейнером отдельных цепей: нельзя объединять `Q` и `NOT_Q` одним электрическим проводом. Выходы `Y0,Y2,Y3,Y4,Y5,Y6,Y7,Y8,Y9,Y10,Y11,Y12,Y13,Y14` идут на отдельные пробники или каналы анализатора, а не соединяются друг с другом. Для наблюдения остановки особенно полезен пробник на `Y6`. HEX оставьте на `Q3…Q0`, как он уже работает.

## Анализатор XLA1

Для отдельной проверки DC переставить каналы `1–14` на `Y0,Y2,Y3,Y4,Y5,Y6,Y7,Y8,Y9,Y10,Y11,Y12,Y13,Y14` в этом порядке. Каналы 15 и 16 свободны. `C` подключить к новому `CLK` и выбрать External (C). Правильный порядок активности — `Y13 → Y2 → Y14 → Y11 → Y0 → Y12 → Y9 → Y5 → Y7 → Y8 → Y4 → Y3 → Y10 → Y6`.

Для записи итоговой остановки тот же XLA перенастроить: каналы `1–4 ← Q3,Q2,Q1,Q0`, `5 ← START_N`, `6 ← P_RES`, `7 ← STOP_SIG` (если выведете контрольную точку из HB4), `8 ← CLK`; остальные свободны. Выбрать Internal около 100 Гц, вход `C` оставить свободным. Иначе после остановки `CLK` внешняя выборка также прекратится и удержание кода `6` не будет видно. Если `STOP_SIG` пока недоступен с верхнего листа, оставьте канал 7 свободным и проверяйте `Q=6`, `Y6=1`, `CLK=1`.

## Порядок первой проверки

1. Сохранить отдельную копию общей схемы для интеграции. Оставить `START_N = 1`.
2. Запустить моделирование. Дождаться `P_RES = 1`; HEX должен показать `D`, а `CLK` — оставаться в `1` до запуска. Если этого нет, сначала проверить цепи `P_RES`, начальную установку `Q1` и питание.
3. Кратко переключить `START_N: 1 → 0 → 1`. При `0` триггер U44A освобождает таймер; не оставлять `START_N` постоянно в нуле, иначе остановка не защёлкнется.
4. Наблюдать 13 положительных фронтов: `D → 2 → E → B → 0 → C → 9 → 5 → 7 → 8 → 4 → 3 → A → 6`. Затем `HEX=6`, `Y6=1`, `CLK=1` и дальнейших фронтов нет. При непрерывном тактировании без механизма остановки следовало бы `6 → D`; здесь этот фронт блокируется.
5. Если схема остановилась раньше, отдельно проверить `STOP_SIG = Q3·NOT_Q2·Q1·NOT_Q0`: он должен быть высоким только при коде `A` (`10`) перед следующим фронтом. Сам вход D U44A регистрирует этот сигнал на переходе `A → 6`.
6. Повторный проход начать с общего сброса `S1` в `P_RES_GEN`, дождаться `P_RES = 1` и только затем дать новый импульс `START_N`. Один лишь импульс `START_N` из удерживаемого `6` не восстановит начальный код `D`.

Для измерения `tH` и периода использовать осциллограф XSC: `A+ → CLK`, `B+ → LM555 OUT` или разрешение таймера, `A−/B− → GND`. Номинальный расчёт из варианта: `tH ≈ 0,661 с`, `T ≈ 1,351 с`. Фактические значения занести в Word только после измерения.

## Расхождение с текущим Word

На текущих расчётных рисунках 2.20 и 3.1 и в таблице 3.1 ещё описана прежняя архитектура с отдельным `RUN`, `U_CTRL:A/B` и `AND2`. На присланном снимке 25.09.2026 узлы `STOP_UNIT` и `U44A` уже включены **внутрь** `CLK_GEN`, вход запуска называется `START_N`. При ручной сборке использовать текущие имена выводов блока. После моделирования рисунки и соответствующие пояснения Word нужно обновить по собственным снимкам проверенной схемы.

Готовая курсовая на шестом снимке полезна как пример расположения блоков и приборов. Электрические соединения следует брать из собственного варианта и действующих блоков выше.
