# Принятые решения

## Оформление

- Для общей структуры, титульных страниц и базовой верстки используется курсовая Рыбина из папки `ГОТОВЫЕ КУРСОВЫЕ 2026`.
- Для технической части синтеза ПСУ на D-триггерах приоритетным образцом оформления и последовательности изложения принят файл `ГОТОВЫЕ КУРСОВЫЕ 2026/27-05-2026_10-56-07.pdf`, поскольку он ближе к индивидуальному варианту.
- По запросу пользователя «Порядок синтеза» сделан подпунктом `2.1.1`; отдельный номерованный подпункт «Исходные данные» из образца убран, а сами исходные данные оставлены списком внутри `2.1`.
- Каноническим считается файл из `deliverables/`, а не рабочие копии в других папках.

## Технические решения

- Модуль счета принят равным 14, поскольку цикл содержит 14 различных состояний.
- Тип триггеров — D, микросхема 74AS74. Формирование входов выполняется по правилу `Di = Qi(t+1)`.
- Распиновка 74AS74 в пояснительной записке взята из официальной документации Texas Instruments, а не перерисована вручную.
- Для дешифратора используется обозначение 4/14 с учетом возможной аппаратной структуры 4/16.
- Неиспользуемые состояния `1` и `15` не включаются в таблицу рабочего цикла и обозначаются символом `X` на картах Карно как факультативные наборы. Фактическое поведение ПСУ в этих состояниях будет определено полученными минимизированными функциями и отдельно проверено после синтеза.
- Группы на картах Карно обозначаются цветными овалами; парные овалы одного цвета у противоположных границ показывают одну склейку через край карты.
- Выбранные минимальные ДНФ `D3…D0` проверены на всех 14 переходах рабочего цикла и оформлены в пояснительной записке формулами (1.2)–(1.5).
- Функциональная схема `Logic_D` выполнена в базисе И–ИЛИ; инверсные сигналы берутся с выходов `/Q` микросхем 74AS74, поэтому отдельные инверторы на структурном уровне не требуются.
- Обозначения `Logic_J`, `Logic_K` и JK-триггеры не используются, поскольку индивидуальный вариант задан на D-триггерах 74AS74.
- До ручного моделирования в Multisim в пояснительной записке используется расчетная временная диаграмма, построенная по индивидуальной последовательности из 14 состояний.
- Рисунок 2.6 является точной учебной реконструкцией общей схемы наблюдения в визуальном стиле Multisim по образцу `27-05-2026_10-56-07.pdf`; он не выдается за экспериментальный снимок реально запущенной модели.
- Для читаемости рисунка 2.6 принято постоянное цветовое обозначение линий: `Q3` — фиолетовая, `Q2` — оранжевая, `Q1` — синяя, `Q0` — бирюзовая; `CLK` остается зеленой, входы `D3…D0` — красными, инверсные выходы в общей шине — серыми.

## Multisim

- Попытки управлять Multisim 14.3 через автоматизацию Windows приводили к зависанию и вылету.
- Решено больше не применять GUI-автоматизацию Multisim.
- Работа продолжается через расчеты, точные инструкции соединения и ручную проверку пользователем в Multisim.
- Для формирования начального состояния `D` (`1101`) у триггера разряда `Q1` сигнал `P_RES` подается на `/CLR`, а логическая единица — на `/PRE`; для разрядов `Q3`, `Q2` и `Q0` сигнал `P_RES` подается на `/PRE`.
- После исправления пользователь вручную подтвердил полный цикл из 14 состояний с возвратом в `D`.
