## Тема

Синтез пересчетного устройства `13-2-14-11-0-12-9-5-7-8-4-3-10-6` на триггерах `74AS74`.

## Параметры

- Номер варианта: 3.
- Тип ПСУ: синхронный с параллельным переносом.
- Модуль счета: 14.
- Последовательность состояний: `13 → 2 → 14 → 11 → 0 → 12 → 9 → 5 → 7 → 8 → 4 → 3 → 10 → 6 → 13`.
- Разрядность состояния: 4 бита (`Q3…Q0`).
- Реализация памяти: D-триггеры `74AS74`.
- Число необходимых триггеров: 4; одна микросхема 74AS74 содержит два D-триггера, поэтому для ПСУ потребуются две микросхемы.
- Дешифратор: 4/14, физически допустима реализация в структуре 4/16.
- Выходной код дешифратора: унитарный.
- Тип логики: TTL.
- Управляемый генератор: на базе LM555.
- Длительность заданного импульса: 0.66 с.
- Период повторения: 1.35 с.
- Индикация состояний ПСУ: цифровая, шестнадцатеричный код.
- Индикация управляющих сигналов: светодиодная, probes.

## Двоичные коды последовательности

| Десятичное | Q3 Q2 Q1 Q0 |
|---:|:---:|
| 13 | 1101 |
| 2  | 0010 |
| 14 | 1110 |
| 11 | 1011 |
| 0  | 0000 |
| 12 | 1100 |
| 9  | 1001 |
| 5  | 0101 |
| 7  | 0111 |
| 8  | 1000 |
| 4  | 0100 |
| 3  | 0011 |
| 10 | 1010 |
| 6  | 0110 |

Неиспользуемые четырехразрядные состояния: 1 (`0001`) и 15 (`1111`). Их безопасное поведение нужно явно определить на этапе синтеза ПСУ.
