# Ручная проверка разделов 2.2 и 2.3

Состояние на 06.09.2026: Word готов до 2.3.3, 23 страницы. Новые иллюстрации — расчётные, не результаты запуска Multisim. Не автоматизировать интерфейс Multisim.

## Дешифратор DC1

1. Открыть рисунок 2.10 (страница 15 Word) или `deliverables/figures_22_23/fig_2_10_decoder_scheme.png`.
2. Собрать 14 элементов: 8 AND3 и 6 AND4. Подписанные входы каждого элемента соединить с одноимёнными Q/NOT_Q регистра D_Counter. На выходы поставить Probe.
3. Выходы называются по десятичному коду: Y13 активен при D, Y2 при 2 и т.д. Y1 и Y15 отсутствуют.
4. Подключить два анализатора по рисунку 2.11: каждый получает Q3..Q0 и семь Y; общий C подключён к CLK, режим External (C).
5. Сравнить с расчётной диаграммой 2.12. Рабочий порядок: Y13 → Y2 → Y14 → Y11 → Y0 → Y12 → Y9 → Y5 → Y7 → Y8 → Y4 → Y3 → Y10 → Y6 → Y13.
6. Сохранить DC1.ms14, снимок схемы и две диаграммы. На 1 и 15 минимизированная схема не унитарна — это описано в Word и не должно считаться сбоем рабочего цикла.

## Генератор GEN_555

1. Начать с отдельной схемы по рисунку 2.14 (страница 19) и таблице 2.2 (страница 21). R1 = 4,32 кОм, R2 = 95,3 кОм, C1 = 10 мкФ; питание +5 В.
2. C2 = 10 нФ между CTRL и GND; C3 = 100 нФ по питанию. CLK брать после инвертора 74LS04, не с вывода 3 LM555.
3. Для проверки таймера без контроллера подключить /RESET (4) к +5 В. XSC: A+ → CLK, B+ → OUT, оба минуса → GND.
4. После нескольких периодов приостановить моделирование. Измерить положительный–отрицательный фронт CLK: расчётно 0,660569 с; положительный–следующий положительный: 1,351082 с. Фактическое отличие модели записать, не подменять его расчётным значением.
5. Сохранить GEN_555.ms14 и два снимка курсоров. Первый запуск от разряженного C1 не использовать для проверки периода.

## RUN и связь с ПСУ

- Дополнительный 74AS74: D (2) = 1; /PRE (4) = 1; CLK (3) = START; /CLR (1) = P_RES; Q (5) → /RESET LM555; питание 14/7 = +5 В/GND.
- P_RES должен одновременно управлять начальной установкой ПСУ и сбросом RUN. Сначала удержать P_RES = 0, затем снять его, затем подать положительный фронт START.
- В остановленном состоянии CLK = 1. Не сбрасывать отдельно только таймер при CLK = 0: после инвертора возникает положительный фронт.
- Контроллер сохраняет непрерывный замкнутый цикл. Автоматическая остановка на 6 здесь не добавлена. Полную интеграцию и переходные процессы ещё необходимо проверить.
