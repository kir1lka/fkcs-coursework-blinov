## DC1 и один анализатор

1. Собрать DC1 по 2.10: восемь AND3, шесть AND4, входы от Q/NOT_Q D_Counter.
2. Рисунок 2.11 (стр. 16): один XLA, каналы 1–14 соответственно Y0,Y2,Y3,Y4,Y5,Y6,Y7,Y8,Y9,Y10,Y11,Y12,Y13,Y14. Каналы 15–16 свободны, C → CLK, режим External (C). Q/T не подключать.
3. Q3…Q0 оставить на HEX. Все 18 Q/Y одновременно в один XLA не помещаются, но для этого способа проверки это не требуется.
4. Сравнить 2.12: Y13 → Y2 → Y14 → Y11 → Y0 → Y12 → Y9 → Y5 → Y7 → Y8 → Y4 → Y3 → Y10 → Y6. На свободном тактовом источнике цикл повторяется; с CLK_GEN останавливается на 6.
5. Сохранить DC1.ms14, схему и диаграмму. Коды 1/15 после минимизации не унитарны; рабочие состояния должны быть унитарными после установления уровней.

## GEN_555

- Окончательная схема — рисунок 2.17 (стр. 21), карта соединений — таблица 2.2 (стр. 22).
- R1=4,32 кОм; R2=95,3 кОм; C1=10 мкФ. C2=10 нФ между CTRL и GND, C3=100 нФ по питанию. CLK с выхода 2 инвертора 74LS04, его вход 1 от LM555:3 OUT.
- Только для отдельного измерения таймера /RESET (4) → +5 В. В общей схеме заменить на RUN; источники не соединять параллельно.
- XSC1: A+→CLK, B+→OUT, A−/B−→GND. Высокий уровень около 0,660569 с, период 1,351082 с. Измерять установившиеся импульсы, не первый запуск.
- Сохранить GEN_555.ms14 и два собственных снимка курсоров для 2.22 и 2.23.

## STOP_UNIT (рисунок 2.18, стр. 23)

Один дополнительный корпус U_CTRL 74AS74 используется целиком, помимо четырёх триггеров памяти ПСУ.

- AND4: Q3, NOT_Q2, Q1, NOT_Q0 → E10. Это точный код 1010, без факультативных наборов.
- Секция B: D12→E10, CLK11→CLK ПСУ, /PRE10→+5 В, /CLR13→P_RES. Q9→STOP, /Q8→NOT_STOP.
- STOP записывается на переходе 10→6: это упреждающий синхронный детектор, а не остановка в коде 10.
- Секция A: D2→+5 В, /PRE4→+5 В, CLK3→START, /CLR1→P_RES AND NOT_STOP. Q5→RUN→LM555:4. /Q6 свободен.
- AND2: 74LS08, входы 1/2→P_RES/NOT_STOP, выход 3→U_CTRL:A:1. Питание корпусов 14→+5 В, 7→GND, развязка 100 нФ; свободные входы фиксировать.

## P_RES_GEN (рисунок 2.19, стр. 24)

- R3=10 кОм от +5 В к RC-узлу; C4=10 мкФ от узла к GND, плюс к узлу, IC=0 В. S_RST замыкает узел на GND.
- 74HC14: узел→1, выход2→вход3, выход4→вход1 74LS07. Два инвертора Шмитта сохраняют исходную полярность.
- 74LS07: выход2→P_RES; R4=1 кОм от P_RES к +5 В. Открытый коллектор требует подтяжки. Пять асинхронных входов 74AS74 и LS08 требуют до примерно 9,4 мА в нуле, с подтяжкой менее 15 мА; LS07 рассчитан на VOL≤0,4 В при 16 мА. Прямо нагружать HC-выход всеми этими входами нельзя.
- Оба корпуса: 14→+5 В, 7→GND, по 100 нФ между питанием и землёй. Свободные входы → GND, выходы свободны. У HC14 свободны входы 5,9,11,13; у LS07 — 3,5,9,11,13.
- P_RES→/PRE Q3,Q2,Q0; их /CLR→1. P_RES→/CLR Q1; его /PRE→1. Также /CLR U_CTRL:B и AND2 сброса RUN.
- Старый цифровой источник P_RES отключить. RC-постоянная 0,1 с не равна длительности импульса: её определяет порог Шмитта. Проверить стартовый низкий импульс с IC=0.

## Общая проверка (рисунки 2.20–2.23)

1. START=0; запустить модель, дождаться снятия P_RES. HEX=D, RUN=STOP=0, CLK=1.
2. START: 0→1→0. Первое изменение CLK — вниз, без пересчёта. Первый положительный фронт при C1=0 В ожидается примерно через 1,0944 с после запуска RUN.
3. 13 положительных фронтов: D→2→E→B→0→C→9→5→7→8→4→3→A→6. Затем RUN=0, STOP=1, CLK=1, HEX=6, Y6=1. Дополнительного фронта к D нет.
4. Проверить отсутствие преждевременной остановки на 7→8. STOP_UNIT регистрирует установившийся предыдущий код; задержки и начальные условия проверить в Multisim.
5. Без сброса START не возобновляет генерацию. Для нового прохода замкнуть S_RST минимум на 5 с (разрядить C1), разомкнуть, дождаться P_RES=1, затем START.
6. Рисунок 2.21: XSC1 A+→CLK, B+→RUN, минусы→GND. Для проверки инверсии временно перенести B+ на OUT; RUN с OUT не соединять.
