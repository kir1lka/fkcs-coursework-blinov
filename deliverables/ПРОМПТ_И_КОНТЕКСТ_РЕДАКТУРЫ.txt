ПРИМЕР А. ПРИНЯТАЯ РЕДАКЦИЯ РАЗДЕЛА 1.1

1 Техническое задание на проектирование
1.1 Цель и содержание курсовой работы

Цель курсовой работы по дисциплине «Функциональные компоненты цифровых систем» – спроектировать управляющее устройство (УУ) в виде цифрового автомата с микропрограммным управлением. Переходы между его состояниями должны выполняться в порядке, заданном индивидуальным вариантом. Каждому состоянию соответствует одна микрокоманда.

Для достижения этой цели необходимо:

- выполнить синтез синхронного пересчётного устройства (ПСУ) на D-триггерах 74AS74, обеспечивающего заданную последовательность состояний УУ;
- разработать дешифратор (DC), который преобразует код каждого рабочего состояния ПСУ в соответствующий управляющий сигнал Yᵢ; выходной код должен быть унитарным;
- составить принципиальные схемы управляемого генератора импульсов на LM555, управляющего D-триггера и цепи начальной установки, рассчитать необходимые номиналы элементов;
- проверить работу разработанных схем в среде NI Multisim;
- оформить расчёты, схемы и результаты моделирования в пояснительной записке.

2 Синтез управляющего устройства
2.1 Синтез пересчётного устройства
2.1.1 Условия задачи

1. Тип ПСУ – синхронное устройство с параллельным переносом.
2. Модуль счёта – 14.
3. Последовательность состояний – 13–2–14–11–0–12–9–5–7–8–4–3–10–6.

5. Индикация состояния – цифровая, в шестнадцатеричном коде.

2.1.2 Порядок синтеза

Сначала составляется граф состояний ПСУ. Каждая вершина обозначает одно из состояний заданной последовательности. Направление дуг показывает, в какое состояние устройство переходит с очередным тактовым импульсом. После состояния 6 последовательность замыкается возвратом к 13. Полученный граф показан на рисунке 1.1.

Рисунок 1.1 – Граф выходных состояний ПСУ

Число триггеров определяется по формуле N = log₂(Amax), где Amax обозначает максимальное значение выходного состояния. Для заданной последовательности Amax = 14. После подстановки в формулу (1.1) получаем:

N = log₂ 14 ≈ 3,8 ≈ 4    (1.1)

Для хранения кода состояния нужны четыре D-триггера. Комбинации 0001 и 1111 в рабочей последовательности не используются.

Регистр состояния строится на микросхемах 74AS74. В одном корпусе находятся два D-триггера. При положительном фронте сигнала CLK каждый триггер принимает значение, поданное на его вход D. Начальная установка выполняется через асинхронные входы /PRE и /CLR, активные при логическом нуле. С прямого и инверсного выходов можно снимать обе полярности сигнала каждого разряда, поэтому дополнительные инверторы для этого не требуются [2]. Распиновка микросхемы приведена на рисунке 1.2.

Рисунок 1.2 – Распиновка микросхемы 74AS74

Чтобы после тактового фронта на выходе триггера появилось нужное значение, его заранее подают на вход D. Это условие записывается как D(t) = Q(t+1). На его основе составляется таблица переходов D-триггера, приведённая в таблице 1.1.
